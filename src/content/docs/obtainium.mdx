their source. Install it first, then select a channel:

You can also download the [JSON import file](/obtainium.json) and import it
from Obtainium's Import/Export page. It contains both channels; select the
one you want. The links above carry the same configuration, not just a URL.

Stable and canary are separate Android applications. Obtainium tracks the
application you import; it does not switch an installed stable app to canary.
Android still requires compatible signing keys and increasing version codes.

## Manual configuration

Use `https://github.com/TensaminDev/Production-Pins` as the source URL, without
`/releases` or a channel suffix. GitHub is detected automatically. If setting
**Override Source** manually, select **GitHub**. The serialized source identifier
is `"overrideSource": "GitHub"`.

Set the release-title filter to `^stable-` or `^canary-`, the APK filter to
`[.]apk$`, and allow prereleases only for canary. Enable architecture filtering
and fallback to older releases. If several compatible APKs remain, select the
correct one; architecture filtering uses filenames and is only a best effort.

The import enables **Release Date as Version** and disables **Version Detection**.
Stable releases are normal GitHub releases; Canary releases are marked as
prereleases. Each numbered release includes one signed universal Android APK.
Obtainium's pseudo-version tracks the release date, while Android still checks
signing identity and version code. The metadata-only `stable` and `canary`
releases have no APKs and are excluded by the title filters.
